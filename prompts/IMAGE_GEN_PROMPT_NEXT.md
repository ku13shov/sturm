Я прикрепил архив с референсами одного объекта:

1. оригинальный пиксельный спрайт из игры 2007 года;
2. 2D-концепт предыдущего уровня;

Вот визуальное направление предыдущего уровня:

> Modern 2.5D/isometric sci-fi RTS central Mars command base, large symmetrical armored command structure based on the original broad mechanical silhouette, dark gray industrial hull, cyan illuminated central control panels, red vertical side modules, angular reinforced outer shell, heavy landing/support geometry, layered command core, believable three-tier upgrade architecture, iconic headquarters silhouette, no text, no flags, fixed 45-degree isometric orthographic-friendly view, isolated pure white background, studio lighting, centered full building with clear sprite silhouette, modern AAA sci-fi strategy aesthetic, clean separated colors and materials, sprite-ready composition with clean separated layers.

Создай 2D-концепт следующего уровня развития того же объекта для последующей сборки 2.5D Godot-сцены.

Оригинальный спрайт определяет базовую форму, назначение, узнаваемый силуэт и исходную цветовую идентичность. Концепт предыдущего уровня определяет актуальный современный дизайн, материалы, пропорции, ракурс, масштаб и визуальный стиль. Предыдущий уровень является главным референсом для визуальной преемственности.

Создай именно улучшенную версию того же объекта, а не новый объект:
- сохрани основной силуэт и узнаваемую конструкцию;
- сохрани исходный тип здания и его функциональные элементы;
- сохрани тот же размер основания и общую посадку на игровом поле;
- сохрани тот же ракурс, ориентацию, масштаб и композицию;
- добавь убедительное усиление конструкции;
- добавь новые броневые панели, усиленные опоры, дополнительные технологические модули и более развитое оборудование;
- сделай освещение и энергосистему более продвинутыми;
- увеличь визуальную сложность умеренно, без перегрузки деталями;
- уровень улучшения должен быть легко заметен при сравнении с предыдущим уровнем;
- изменения должны выглядеть как естественная модернизация, а не полная переделка;
- не добавляй случайные антенны, оружие, здания или декоративные элементы без функционального объяснения.

Изображение должно быть пригодным для 2.5D Godot-сцены и последующей 2D-анимации:
- строго один объект;
- объект целиком помещается в кадр;
- читаемый замкнутый силуэт;
- видны передняя, боковая и верхняя поверхности;
- фиксированный 45-градусный изометрический трехчетвертной ракурс;
- минимальная перспективная деформация;
- никаких обрезанных частей;
- без персонажей, транспорта и дополнительных объектов;
- без текста, логотипов, флагов и UI;
- прозрачный фон (альфа-канал) для прямого использования в PNG Sprite2D;
- без пола, горизонта, окружения, дыма, пыли и фоновых деталей;
- без тени под объектом и без падающих теней;
- мягкое равномерное студийное освещение;
- объект по центру с одинаковыми безопасными полями вокруг;
- чистые, хорошо разделенные поверхности и материалы;
- production-ready 2D game concept для последующей сборки Sprite2D/AnimatedSprite2D-сцены;
- сохранённый силуэт и набор слоёв должны быть пригодны для cutout-анимации и сценного редактирования.

Сгенерируй только следующий уровень этого объекта.

Для последующей анимации и сборки Godot-сцены:
- сохраняй одинаковый canvas, масштаб, pivot и положение основания относительно предыдущего уровня;
- выделяй потенциально движущиеся части: оружие, антенны, двери, верхние модули, огни и отдельные панели;
- не смешивай движущиеся части с корпусом, если их можно анимировать отдельно;
- результат должен подходить для Sprite2D, AnimatedSprite2D, AnimationPlayer или cutout-анимации;
- не генерируй видео и случайные промежуточные кадры: важнее стабильный силуэт, чистые слои и возможность вручную собрать состояния active, damaged, attack и destroyed.
