# Mars Tile Variants — image-generation prompt

## Как использовать прикреплённый архив

В архиве находятся ассет старой оригинальной игры, ассеты уже сгенерированной современной центральной базы в трёх вариациях и текущий ассет новой карты/грунта. Используй три вариации современной базы как главный референс для палитры, материалов, освещения, масштаба деталей и общего 2.5D/isometric sci-fi RTS-стиля. Оригинальный ассет используй только как историческую справку; не копируй `res://original/000.png`, его пиксельную стилистику, структуру или детали. Текущий ассет новой карты используй как рабочий референс для согласования с уже выбранной поверхностью, но сделай варианты более stylized и менее фотореалистичными, если это требуется для соответствия базе.

Создай несколько новых вариантов бесшовных тайлов для карты. Новая карта строится отдельно, а варианты должны сочетаться с современной базой и базовым Mars Ground texture.

## Основной запрос

> Set of distinct seamless Mars terrain tile variants for a modern 2.5D isometric sci-fi RTS, consistent with one shared material system: rusty red-orange regolith, darker compacted soil, ochre mineral dust, shallow wind-carved channels, sparse small basalt fragments, subtle dry cracks, occasional darker rocky patches, varied but controlled visual density, no obvious repetition, modern AAA strategy-game environment texture treatment, orthographic-friendly, readable beneath buildings and units, no retro pixel art.

## Состав вариантов

Подготовь визуально согласованные варианты поверхности:

1. базовый равномерный Mars regolith;
2. более тёмный compacted soil для контраста;
3. светлая пыльная mineral patch;
4. мелкая cracked/dry channel зона;
5. более каменистая rocky soil зона;
6. мягкий переходный вариант для смешивания без резкой границы.

Каждый вариант должен сохранять общую палитру и масштаб деталей, но иметь достаточно отличимую текстуру, чтобы карта не выглядела однообразной.

## Технические требования

- Каждый tile бесшовен по горизонтали и вертикали; seamless только для ground/tile-текстур.
- Не добавляй крупный уникальный объект, центр композиции, рамку, перспективу, горизонт, UI, текст, логотипы или grid lines.
- Не добавляй края карты, стены или скальные formation в сами ground-варианты — краевые элементы генерируются отдельными ассетами.
- Непрозрачный RGB или RGBA допустим; каждый вариант должен быть пригоден для Godot TileMap/TileMapLayer.
- Рекомендуемый размер каждого тайла: 512×512 или 1024×1024; одинаковый размер и texel density обязательны.
- Сгенерируй набор отдельных статичных тайлов, не sprite sheet и не анимацию, если это не требуется инструментом отдельно.
- Без старых пиксельных элементов и без визуального копирования исторического `000.png`.
