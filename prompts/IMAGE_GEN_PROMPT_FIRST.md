Я прикрепил оригинальный пиксельный спрайт объекта из игры 2007 года.

Создай современную 2D-концепт-версию этого же объекта для последующей сборки 2.5D Godot-сцены. Используй оригинальный спрайт как строгий референс формы, силуэта, пропорций, цветовой схемы и функционального назначения. Не создавай новый объект с другой конструкцией и не меняй его на другой тип здания.

Используй этот точный визуальный промпт:
> Modern 2.5D/isometric sci-fi RTS Mars infantry defender, compact armored human soldier based on the original blue-and-white uniform silhouette, protective helmet, dark tactical body armor, blue visor/energy accents, rugged boots and gloves, compact rifle held in a ready position, practical colonial military design, readable from an isometric strategy camera, no excessive tactical accessories, fixed 45-degree isometric orthographic-friendly view, isolated pure white background, studio lighting, centered full-body character, modern AAA sci-fi strategy aesthetic, clean separated colors and materials, sprite-ready composition with clean separated layers.

Изображение должно быть технически пригодным для 2.5D Godot-сцены и последующей 2D-анимации:
- строго один объект;
- объект показан целиком;
- хорошо читаемый внешний силуэт;
- видны передняя, боковая и верхняя поверхности;
- фиксированный 45-градусный изометрический трехчетвертной ракурс;
- нейтральная поза и неподвижная конструкция;
- чёткий плоский силуэт, пригодный для Sprite2D или слоёв cutout-анимации;
- без сильной перспективной деформации;
- без обрезанных частей;
- без тонких случайных деталей, сливающихся с фоном;
- без персонажей, транспорта, дополнительных модулей или объектов;
- без текста, логотипов, флагов и UI;
- прозрачный фон (альфа-канал) для прямого использования в PNG Sprite2D;
- без пола, горизонта, окружения, дыма, пыли и фоновых деталей;
- без тени под объектом и без падающих теней;
- мягкое равномерное студийное освещение только для читаемости формы;
- объект расположен по центру кадра с запасом по краям;
- материалы и детали должны быть четко видны, но изображение должно оставаться чистым production concept art.

Не добавляй элементы, которых нет в оригинальном спрайте, если они не требуются для логичного современного 2.5D-дизайна.

Для последующей анимации подготовь объект так, чтобы его можно было собрать
в Godot-сцене:
- сохраняй одинаковый canvas, масштаб, pivot и положение основания во всех состояниях;
- выделяй потенциально движущиеся части: конечности, оружие, антенны, двери, верхние модули, огни;
- не смешивай движущиеся части с корпусом, если их можно анимировать отдельно;
- базовый результат должен быть пригоден для Sprite2D, AnimatedSprite2D, AnimationPlayer или cutout-анимации;
- не генерируй видео и не добавляй случайные промежуточные кадры: важнее стабильный силуэт и отдельные читаемые слои.
